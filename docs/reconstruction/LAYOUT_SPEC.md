## 日曆與右側篩選

沒有介紹文案、統計卡、後續安排卡或提示裝飾卡。日曆緊接頂欄，沒有主頁外距、卡片圓角或卡片間隙。

桌面主區為兩欄：日曆minmax(0,1fr)，右篩選固定300px，兩者相鄰。右篩選背景#f8f9fa、左框1px #ddd、16px內距。900px仍為兩欄，不任意把篩選移到下方。≤768px常駐篩選隱藏，右下距16px的56px浮動篩選鈕開啟300px右抽屜；抽屜16px內距，上排標題左／關閉右，下方順序與桌面相同。遮罩、Esc及關閉鈕均可關閉；抽屜內鍵盤焦點不外漏，關閉回原控制。S/I。

工具列左右20px、上下10px內距，至少64px高，左「上一期／下一期、今天」，中間日期標題，右「月／週／天／活動列表」，之後為權限允許的「隱藏節日／顯示節日」。按鈕#2c3e50、白字、1px邊框、4px圓角、至少34px高；標題24px/1.2，週標題顯示實際週範圍。≤1100px主欄空間不足時視圖组換到第二列；≤768px內距10px/8px、標題17.6px、按鈕至少40px。≤480px上一期／今天及標題同列、視圖與假日按鈕次列。換行細节屬I，原CSS最終網格呈現仍U。

右側依序：

1. 「日期」標題20px/1.6、下距16px；內嵌小日曆。小日曆寬100%、1px #aeaeae框、4px圓角，上方灰色月份列36px、左右箭頭；週一開始七欄，每格34×30px（隨容器均分）。選中藍色底白字，今天有框，非本月灰字。這些小日曆細尺寸為I，位置與週一開始為S。
2. 16px後「車牌：」收合區，初始收合；標題列至少48px高、8px內距、#00000005背景、1px #e0e0e0框、4px圓角，箭頭靠右。展開內容上距8px、內距8px 8px 8px 16px、背景#fafafa。已選chip在上、全選在下、個別車牌列表在最後；chip依車色、黑字，删除鈕靠右。列表最大200px高且縱捲。勾選框左、12px色點中、車牌右；收合不清除選取。S。
3. 「作業區」標題，上距16px／下距8px；勾選框、12px橘色點、文字「作業區預約」同列。S。
4. 保留现行「儀器設備」勾選，同樣用紫色點；放在作業區後，不新增獨立卡片。R（歷史來源沒有E事件，本次保留差異）。

車輛八色依資源API順序循環：#90caf9、#a5d6a7、#ffcc02、#ce93d8、#ffab91、#cceeff、#ffcccc、#d7ccc8；資源日車牌按文字排序，不改变既定顏色。作業區#FF9800、儀器#ce93d8、假日#C8E6C9；事件黑字且無時間前綴。S/R。

## 視圖、選取與資料

- 初始月視圖、週一開始、顯示週末；保留現行全部有效車輛初始勾選（R），原站初始空選車記錄為差異；車牌區本身初始收合（S）。
- 上一期／下一期按月、週、日或列表週移動，今天返回臺北當日；小日曆月份跟隨主日期、選日直接切資源日。切換視圖保持日期和所有篩選。選日不寫資料。
- 月：七欄，日期置中，跨日分段，超量以「顯示更多」；桌面月格至少98px，手機至少60px且主內容至少500px。週：00:00～24:00、半小時格、無全天列、08:00～18:00營業背景、現在時間指示。
- 資源日：自製HTML/CSS時間表，左時間欄58px，車輛／作業區／儀器各至少120px（手機140px）；不足時只在時間表內橫捲；00:00～24:00，每半小時30px高。事件以開始／結束對應高度，跨日裁切，結束端點不多占下一格；重疊事件並列。表頭黏住頂部。空篩選顯示提示，不產生假資源欄。
- 點空白時段／拖選開選擇卡，保留開始、結束及車輛ID；手機可點選。可建立種類依現有create權限；作業區、儀器欄清除車輛預選。23:30末格結束為翌日00:00。前端不直接保存，接入現行A/D/E路由。
- 事件點擊開既有摘要：ID／狀態、標題、申請人／類型、各資源時段、右下完整申請入口；detail_allowed=false不得開他人完整申請。點擊假日不開詳情。本批不改寫完整申請／流程／保存。
- 時間統一Asia/Taipei，依現行businessDate契約解析無時區資料，不能沿用原站混合本地／UTC缺陷。
- 假日切換只對ui權限Enabled或Visible顯示，載入時不能切換；使用API真實回應，不在畫面宣稱所有環境都是示範。取得失敗顯示錯誤，不填假資料。
