## 每段工作方式

1. 確認本段來源、欄位、布局與資料契約，不用原畫面程式當成果。
2. 寫出具體布局規則與證據／未知標記；保留目前正常的路由、權限、保存、資料相容及使用者變更。
3. 自行實作 React／HTML／CSS；檔案可拆成易理解的共用 panel、編輯列、表格、時間欄與圖片元件。
4. 在隔離資料與服務上驗證本段，包含保存後回讀，避免用正式資料做測試。
5. 更新規格、必要部署／操作文件；提供可操作預覽、桌面／手機截圖、測試結果及差異清單。
6. 納入使用者回饋，接續下一段；不用反覆請使用者批准已授權的例行實作。
