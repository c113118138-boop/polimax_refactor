## 查詢與表單彈窗

來源 `formio/HistoryRecords.jsx`、`Departure_query.jsx`、`Back_query.jsx`，以及 `components/MainContent/FormioEditor.jsx`。

### 歷史紀錄

`/bookings?history=1` 只列已完成 A 單，使用原查詢表格外框、20px 內容內距。保留使用者例外的英文小標與介紹文案。標題列之後是篩選卡，再接表格；不用額外狀態快選。11 欄順序：表單編號、車牌、申請緣由、地點、開始時間、結束時間、業務人員、申請人、申請時間、總里程數、操作。

每個占用時段一列；同單的編號、總里程與操作合併。篩選後按實際留下的列數合併。總里程為 C 抵達里程減 B 出發里程；缺有效階段顯示缺資料，讀取失敗可重試，不填假數字。查看操作依序為主表藍色、B 綠色、C 紫色、軌跡橘色，需相應 read 權限；缺階段不可開啟假表單。轨跡帶車輛與起訖至 `/positions`。

### 發車／還車查詢

分開 `/stages?kind=B`、`/stages?kind=C`。標題與新增按钮同列，篩選卡在下，表格五欄：表單編號、日期、駕駛人、車牌、操作。篩選選項：全部顯示、依日期、依車牌、依駕駛人；日期使用含起訖日的台北日期，文字不分大小寫，清除恢復全部。

日期依原 API 的 B `panel2`／C `page4`，對應現行 `content.start.submitted_at`，顯示 `YYYY-MM-DD HH:mm`。缺舊送出時間時退回 created_at。不能把預約時間或只有日期當送出時間。

查看、編輯、刪除使用列內圖示；B 修改需本人父單或管理員，摘要不得開啟明細。新增需選有效 A 父單，B 對應待發車、C 對應發車已抵達，繼續既有四階段流程，不建立無父單的孤立紀錄。保存後重讀，修訂不倒退父單狀態。

### 自製表單彈窗

A/D/E 與 B/C 查看／編輯均沿用自製表單。彈窗寬800px、上限 viewport 減40px、max-height90vh、外距20px、圓角8px；內容內距20px，遮罩與右上關閉；超出內容向下捲動。B/C 既存紀錄同時顯示出發與抵達區塊。唯讀禁用欄位、隱藏上傳與列增刪／保存；查看不能改資料。

正常點擊查詢列開浮層；原深層 href 仍可直接進入／刷新或另開分頁。編輯取消、Esc、側欄與登出繼續共用離頁確認；保存／上傳中不可放棄，錯誤保留輸入，revision409不靜默覆蓋。

### 車輛五分頁與資訊卡

基本資料內距24px；藍色#1976d2標題卡，24px內距，圓角4px，車牌32px。下方等寬雙欄資訊卡、間距24px；小於900px改一欄。基本資訊：車牌、廠牌型號、車主、購買日期、金額、乘客數；聯絡資訊：聯絡人、電話、管理人。設備、備註與檔案各滿行。文件區桌面三欄：行照、車籍資料、合約；小於900px直排。

`/equipment/:id` 同樣標題卡与資訊卡，沒有車輛分頁。左基本資訊：設備編碼、位置編號、品牌／購買／維修廠商、數量、用途；右管理資訊：保管人、列管建議、預估價值、委外校正日期、有效期限。其後滿行配件、備註、文件。三類文件以原新增及詳情一致的「使用手冊、保固書、採購文件」為準，不套用車輛文件或誤稱成校正證明。

小於600px內容／標題卡內距16px、資訊卡20px、標題25px。缺欄位顯示空值符號，不生成不存在的個資、文件或圖片。

## 定位四頁

S 來源 `Map/CarMap.jsx`、`CarUpdate.jsx`、`FindMy.jsx`、`Latest_Device_Table.jsx`。四頁各自固定用途，不合併在同頁 tabs。

共用兩欄：左350px白色面板、右剩餘寬度地圖或列表；內容可捲動、兩邊無頁面橫向溢出。地图畫布至少500px，主區扣85px頂欄，保留使用者例外介紹文字。手機判斷 max-width768px：左面板隐藏，右下16px浮動查詢按鈕，從右開90vw／max400px抽屜，關閉後回地圖；浮動按鈕固定在手機視窗右下角，地圖內容建立獨立層級，避免捲動後蓋住正常頂部選單。769px仍保留350px左欄。斷點切回桌面時关闭手機抽屜。

- 即時位置 `/positions`：左車輛搜尋與卡片，卡片有車牌、最後更新、來源、無有效座標狀態；點卡片選中與地圖聚焦，保留目前有效設備資料。每10秒重讀与手動刷新；刷新不偽造報告時間。選中有提示与地圖 popup。
- 軌跡 `/positions?view=history`：左車輛、開始、結束、查詢與位置卡；右軌跡，起點綠、終點紅、其他藍。預設台北今日00:00:00～23:59:59；既有30／60／90天与自訂時間保留在快捷摺疊區。deep link有車輛／起訖時可重查。無座標保留缺值提示、不要把中間缺值前後連成假軌跡；查詢失敗保留條件，能重試。
- FindMy `/findmy`：左搜尋設備、選擇、設備 ID、擁有者、MAC、最後更新、座標、建立時間、精確座標与清除；右設備定位。精確座標顯示六位小數；每10秒刷新並顯示「即時更新」，手機關閉右側抽屜後仍有選中設備／時間提示。保留Major；没有定位明確显示，不能使用初始化台灣中心冒充設備位置。
- 場內掃描 `/scans`：左搜尋站點與站點列表，右選中站點、總數／在線／離線／更新時間、三欄設備名稱／更新時間／設備狀態；RSSI／電量延伸資料保留在可展開儲存格。每10秒刷新，5分鐘在線規則由既有 API 判定。

數值座標必須有限且在緯度±90、經度±180範圍內；空值不畫點。地圖以 Leaflet+OpenStreetMap 既有方式呈現；圖資載入錯誤有提示，資料卡仍可用。正式 GPS、FindMy Apple session、MQTT 接收器不是此次匿名定位 fixture 的驗收成果。
